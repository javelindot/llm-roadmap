# 手写双塔模型的损失函数(Batch内负采样实现)

## 答案

双塔常用 **in-batch InfoNCE**：对匹配的用户/物品对，batch 中其他物品作为负例，最大化正确配对的 softmax 概率。
```python
import torch
import torch.nn.functional as F

def in_batch_loss(users, items, temperature=0.07):
    """以 batch 对角线为正例计算双塔损失，输入为匹配的二维向量。"""
    if users.ndim != 2 or users.shape != items.shape or len(users) == 0:
        raise ValueError("matched nonempty embeddings required")
    if temperature <= 0:
        raise ValueError("temperature must be positive")
    u = F.normalize(users, dim=1)
    v = F.normalize(items, dim=1)
    logits = u @ v.T / temperature
    labels = torch.arange(len(u), device=u.device)
    return F.cross_entropy(logits, labels)
```
相似度计算时间 O(B²d)，矩阵空间 O(B²)。重复物品/多个正例需要 mask 或多正例目标；跨卡 gather 要明确梯度传播。B=1 没有负例，不提供有效对比信号。
