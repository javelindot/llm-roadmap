# Attention机制的原理及应用

## 答案

**注意力让当前位置按内容相关性聚合其他位置的信息。** 输入 X 分别投影为 Q=XW_Q、K=XW_K、V=XW_V，计算 Attention(Q,K,V)=softmax(QK^T/√d_k+mask)V。
Q 表示查询，K 用于匹配，V 是被聚合的信息。缩放因子防止大维度点积使 softmax 过度饱和；mask 限制可见范围，例如屏蔽 padding 或未来 token。
自注意力的 Q/K/V 来自同一序列，交叉注意力的 Q 来自一侧、K/V 来自另一侧。应用包括语言建模、机器翻译、图像 patch 建模、多模态融合；标准全注意力的时间和注意力矩阵空间开销随序列长度平方增长。
