# 二面:大模型生成内容的评测方式有哪些，具体怎么操作？

## 答案

生成评测采用**任务可验证指标 + 人工评审 + 校准后的模型评审**。问答检查事实、引用、完整性和拒答；摘要看要点覆盖与忠实性；代码跑隔离测试；结构化任务校验 schema 及业务约束。
建立独立、分层的评测集，写清评分 rubric，人工盲评并检查一致性。模型 judge 需交换候选顺序、避免泄露身份，并与人工结果比对。
离线比较质量、失败类型和置信区间，线上看真实任务成功率、反馈、延迟与成本。BLEU/ROUGE 或 embedding 相似度只能提供局部信号，不能单独证明答案正确。
