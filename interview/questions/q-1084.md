# 为什么BERT在第一句前会加一个[CLS]标志? BERT输出的两个函数是什么？

## 答案

**[CLS] 是用于汇总序列表示的特殊 token，其最终隐状态常送入分类头。** 它能通过双向注意力聚合整段输入，但并非无需训练就天然是最好的句向量。
“两个函数”若指原始 BERT 预训练任务，分别是 MLM（预测被遮蔽 token）与 NSP（预测句子对是否相邻）。若指模型输出，常见 sequence output 是每个 token 的向量，pooled output 则是 CLS 经变换后的向量，具体库输出取决于实现。
应先确认问的是训练目标还是 API 返回值；下游分类可使用 CLS、池化或专门训练的句向量表示。
