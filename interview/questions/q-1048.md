# 3.ChatGPT对语音助手的冲击有哪些，会从哪些方面影响到现在的语音助手

## 答案

LLM 对语音助手的影响主要是**开放式理解、多轮上下文、复杂任务分解及自然语言生成**，能扩展原有意图槽位系统的覆盖。但语音链路仍要处理 ASR、端点检测、TTS 或原生实时语音。
产品体验取决于首响应时间、打断、噪声、口音、误唤醒与网络波动；工具执行还需明确确认、权限和幂等，不能因表达自然就默认执行高成本动作。
评价应同时看语音识别错误、任务成功率、端到端延迟和取消成功率。可把稳定高频指令交给规则/专项模型，开放复杂问题由 LLM 处理。
