# 🔥 reward function 如何设计的为什么这么设计？

## 答案

**奖励函数应对应可验证的任务结果，并控制被模型钻空子的空间。** 例如代码任务以隔离环境中的测试通过率为核心，数学任务检查答案正确性，工具任务检查最终业务状态和权限合规。
可以使用 R=w1·正确性+w2·格式+w3·证据质量-w4·违规，但权重需通过量纲归一化、分项日志和消融实验确定。硬安全边界应在执行层强制实现，不能只靠负奖励。
先建立人工标注或规则基准，检查奖励与人工偏好的相关性，再监控 reward hacking、长度偏差和 OOD 表现。面试中的权重、提升幅度及样本规模应填写真实实验结果。
