# 根据需要实现对输入法的算术表达式按照运算法则进行求值

## 答案

**用递归下降解析优先级，不直接执行用户输入。** 下例支持整数、空白、括号、一元正负号和四则运算；除法采用实数除法。
```python
import re

def calculate(expression):
    """解析四则表达式；非法符号、括号错误和除零会报错。"""
    tokens = re.findall(r"[0-9]+|[()+*/-]|\S", expression)
    pos = 0

    def factor():
        """处理数字、括号和一元正负号。"""
        nonlocal pos
        if pos >= len(tokens):
            raise ValueError("missing operand")
        token = tokens[pos]
        pos += 1
        if token in ("+", "-"):
            value = factor()
            return value if token == "+" else -value
        if token == "(":
            value = expr()
            if pos >= len(tokens) or tokens[pos] != ")":
                raise ValueError("missing closing parenthesis")
            pos += 1
            return value
        if token.isascii() and token.isdigit():
            return int(token)
        raise ValueError("invalid operand")

    def term():
        """乘除先于加减，并按从左到右结合。"""
        nonlocal pos
        value = factor()
        while pos < len(tokens) and tokens[pos] in ("*", "/"):
            op = tokens[pos]
            pos += 1
            right = factor()
            value = value * right if op == "*" else value / right
        return value

    def expr():
        """解析加减，括号内部复用同一表达式规则。"""
        nonlocal pos
        value = term()
        while pos < len(tokens) and tokens[pos] in ("+", "-"):
            op = tokens[pos]
            pos += 1
            right = term()
            value = value + right if op == "+" else value - right
        return value

    result = expr()
    if pos != len(tokens):
        raise ValueError("unexpected token")
    return result
```
时间 O(n)，token 和递归空间 O(n)。例如 2*(3+4)-5/2=11.5。深度与输入长度应在服务层限制；金额计算需改用 Decimal，整数截断除法则要另定语义。
