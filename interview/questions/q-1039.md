# QLoRA是怎么降低资源成本的?NF4和FP16这组组合为什么有效?

## 答案

**QLoRA 量化并冻结基础权重，只训练低秩适配器，以降低模型加载和优化器成本。** 论文方案包括4-bit NF4、double quantization 和 paged optimizer 等技术。
NF4 按近似正态分布设计量化等级，适合许多预训练权重分布；计算时通常将量化块反量化到 BF16/FP16，与较高精度适配器一起计算，因此“4-bit 存储”不等于所有运算都是4-bit。
仍有量化元数据、激活和临时缓冲开销，并可能损失精度或增加反量化成本。选型比较显存、训练吞吐与质量，NF4 与 FP16 并非唯一有效组合。
