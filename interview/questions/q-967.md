# 有没有做过工具调用失败后的feedback策略设计？

## 答案

**工具失败反馈应告诉 Agent 错误类别和允许的下一步，而不是只返回一段异常堆栈。** 例如返回 `code`、`retryable`、`execution_status`、`safe_message` 和 task_id。

参数校验失败可以给出具体字段，让模型有限次数修正；权限拒绝应停止动作；短暂读请求故障可退避重试；写操作结果未知则先查幂等状态。反馈中不要泄露密钥、内部地址或敏感数据。

重试次数受总任务预算约束，重复同一错误时终止并转人工。替换工具前确认它的权限与语义一致，不能为了完成任务绕开审批。

评估看最终恢复成功率、重复调用率、额外成本和副作用一致性。回答个人经验时给出真实失败链路及改进前后的数据。
