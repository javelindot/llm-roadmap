# 是否自己实现过 RLHF 流程？不用框架能否手写 PPO 核心逻辑？

## 答案

若没有手写完整 RLHF，应如实说明。可以解释并实现 **PPO 的策略裁剪损失**：
```python
import torch

def ppo_policy_loss(new_logp, old_logp, advantage, mask, eps=0.2):
    """计算有效回答 token 上的 PPO 损失，旧策略和优势不参与反传。"""
    if mask.sum().item() == 0:
        raise ValueError("empty token mask")
    ratio = torch.exp(new_logp - old_logp.detach())
    adv = advantage.detach()
    raw = ratio * adv
    clipped = ratio.clamp(1 - eps, 1 + eps) * adv
    return -(torch.minimum(raw, clipped) * mask).sum() / mask.sum()
```
这是核心 loss，不是完整训练器。完整流程还需 rollout、奖励/KL、终止 mask、GAE、价值更新、优化器和分布式同步。old_logp 固定于采样策略，reference 则用于控制偏离；两者作用不同。
