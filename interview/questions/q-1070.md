# MoE模型的专家数量是如何确定的？

## 答案

**专家数量是质量、激活预算、总参数与通信成本共同决定的超参数。** 在 FFN 宽度和 top-k 固定时，增加专家主要增加总容量，而每 token 激活计算未必按相同比例增长。
更多专家可能改善专业分工，也可能导致每专家训练样本不足、负载不均、all-to-all 成本和部署显存上升。top-k、共享专家、负载约束及设备拓扑需一起设计。
用同数据与计算预算比较专家利用率、overflow、质量、吞吐和尾延迟。没有一个由任务数量直接决定专家数的通用公式。
