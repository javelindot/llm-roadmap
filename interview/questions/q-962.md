# 构建 Agent 的时候，遇到过哪些瓶颈？LangChain 的 memory 默认机制在多用户并发中怎么做隔离？你是如何保证线程安全的？

## 答案

常见瓶颈是上下文膨胀、工具等待、循环调用和多用户状态串扰。**框架提供 memory 接口，不代表它自动满足多租户隔离。** 需要按所用 LangChain/LangGraph 版本确认具体存储语义。

会话状态用 `(tenant_id, user_id, conversation_id)` 作为授权范围内的键，身份从可信会话取得。每个请求持有独立状态快照；禁止把所有用户的消息放入一个进程级共享列表。

同一会话的并发写入可用串行任务队列、数据库版本号与条件更新，或事务控制。线程锁只保护当前进程，多进程和多实例还需要共享存储的一致性机制。

监控排队、模型、检索、工具耗时及状态冲突。验收用两个租户的同名会话、并发消息和重试请求，检查是否串话、丢失更新或重复执行动作。
