# DPO 训练的过程是怎么样的，正负概率怎么算

## 答案

DPO 对每个提示提供**chosen 与 rejected 两条回答**，用相同聊天模板编码，并只对回答 token 计算条件概率。
```text
log π(y|x) = Σ_t log π(y_t | x, y_<t)
score = β[(logπθ(chosen)-logπref(chosen))
         -(logπθ(rejected)-logπref(rejected))]
loss = -log sigmoid(score)
```
训练策略参与反向，参考模型固定；正确对齐 token、EOS、padding 和截断，通常无需把概率连乘，以免下溢。chosen/rejected 是偏好标签，不是普通二分类的0/1概率。
验证偏好胜率、通用任务和长度偏差，β 与训练强度需调节。
