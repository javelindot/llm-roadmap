# 如何确保大模型输出内容的一致性？

## 答案

**先定义一致性是结构稳定、事实一致还是重复调用完全相同。** 结构用 JSON Schema/类型校验；事实用版本化检索证据、明确来源及计算工具；业务状态由服务端保存并校验。
固定模型版本、模板和采样参数，降低 temperature 可减少随机性，但分布式计算等因素仍可能使 temperature=0 不完全确定。关键输出可缓存或由确定性程序产生。
用同义改写、重复请求、多轮冲突和模型升级回归集测试。不能为了“始终同一个答案”掩盖证据更新；一致性应包含对新证据的正确修正。
