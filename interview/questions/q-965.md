# 你的 Agent 系统Prompt 是怎么设计和迭代的？有没有做过 Prompt 自动优化？当用户提出不完整的请求时，如何补全用户意图的？

## 答案

系统 Prompt 应明确角色、目标、可信数据来源、工具边界、输出格式和停止条件。权限由应用执行，不能只靠提示词保证。

迭代流程是收集脱敏 bad case、分类失败原因、修改一个变量、运行固定回归集、比较基线，再灰度上线。记录模型、提示词、工具 Schema 和知识版本，避免无法复现。

自动优化可用候选提示词生成与评测筛选，但要区分开发集和保留测试集，控制额外调用成本，并人工审查是否出现过拟合或越权策略。

用户意图不完整时，先从授权上下文补全低风险信息；涉及金额、时间、对象或不可逆动作时必须澄清。不要凭模型猜测收款人。项目回答应提供自己的真实案例和测量结果，没有做过自动优化就说明实际采用的人工迭代方式。
