# 手撕LeetCode 241题：为运算表达式设计优先级

## 答案

**枚举每个运算符作为最后一步，递归组合左右结果，并缓存子区间。** 题目只含非负整数和 +、-、*；不同括号方案产生的重复结果应保留。
```python
import re
from functools import lru_cache

def diff_ways(expression):
    """返回表达式所有合法二叉括号划分的计算结果。"""
    if not re.fullmatch(r"[0-9]+(?:[+*-][0-9]+)*", expression):
        raise ValueError("invalid expression")
    tokens = re.findall(r"[0-9]+|[+*-]", expression)

    @lru_cache(None)
    def solve(left, right):
        """按最终运算位置分治，并缓存不可变结果元组。"""
        if right - left == 1:
            return (int(tokens[left]),)
        results = []
        for i in range(left + 1, right, 2):
            for a in solve(left, i):
                for b in solve(i + 1, right):
                    op = tokens[i]
                    results.append(a + b if op == "+" else
                                   a - b if op == "-" else a * b)
        return tuple(results)

    return list(solve(0, len(tokens)))
```
k 个运算符有卡特兰数 C_k 种括号结构，输出规模本身指数增长；缓存减少重复子问题但不能消除结果空间。例如 2*3-4*5 返回 [-34,-10,-14,-10,10]（顺序可不同）。
