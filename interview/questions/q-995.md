# CNN和Transformer的区别及适用场景

## 答案

**CNN 通过局部卷积和权重共享提取特征，Transformer 通过注意力动态建模 token 之间的关系。** CNN 具有较强局部和平移相关归纳偏置，计算通常随像素/token 数线性增长；全注意力的关系计算通常为 O(n²d)。
Transformer 更容易连接远距离信息，可处理文本、图像 patch 和跨模态交互，但往往更依赖数据、位置设计与训练策略。CNN 也能通过多层/空洞卷积获得大感受野。
资源有限的局部视觉任务可优先 CNN，长程关系和多模态任务可考虑 Transformer；混合架构也很常见。不能把两者简单描述成只能做图像或只能做文本。
