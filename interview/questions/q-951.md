# 介绍一下ViT、说一下多头自注意力机制的原理和应用

## 答案

**ViT 把图像切成固定大小 patch，映射成 token 后输入 Transformer。** 若图像尺寸 H×W、patch 边长 P，则 token 数约为 (H/P)(W/P)，加位置编码后通过多层自注意力和 MLP；分类可用 CLS token 或池化。
多头注意力在多个投影子空间分别计算 softmax(QK^T/√d_k)V，再拼接并做输出投影，能建模不同类型的全局关系。每头通常分摊总维度，而非把计算无条件扩大到头数倍。
ViT 的全局建模能力强，但对数据规模与训练策略较敏感；CNN 具有局部和平移相关的归纳偏置。视觉语言模型可将视觉 token 经投影器与语言模型连接。
