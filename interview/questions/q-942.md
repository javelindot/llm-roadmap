# 4.阐述大模型训练与推理的完整流程。

## 答案

训练链路通常是数据收集与去重、tokenization、预训练、SFT，再按目标进行偏好优化或强化学习。每阶段都需要数据隔离、验证集、checkpoint、数值稳定和能力回归；不是所有应用都要从预训练开始。

预训练学习通用分布，SFT 学习指令与示范，偏好或 RL 阶段优化人类偏好、可验证结果或任务奖励。发布前还要做安全、领域、通用和性能评测。

自回归推理包括加载模型、构建输入与模板、prefill 处理已有上下文、逐 token decode、采样和结束判断。KV Cache 避免重复计算历史 K/V；动态批处理、优化算子和并行提升服务效率。

部署时加入鉴权、限流、超时、取消、监控、预算和灰度。模型离线分数合格与完整应用可以可靠上线是两项不同的验收。
