# DPO的公式给我写一下或者口述一下？当时没写出来🙄

## 答案

**DPO 损失为负对数 sigmoid 的相对偏好分数：**
```text
L = -E[log σ(β(
    log πθ(y+|x) - log πref(y+|x)
  - log πθ(y-|x) + log πref(y-|x)
)))]
```
x 是提示，y+ 为优选回答，y- 为劣选，πθ 是当前策略，πref 是固定参考模型，β 控制相对参考分布的优化尺度。
回答 log probability 通常是回答 token 的条件 logprob 之和，只对回答计算，正确处理 EOS、padding 和聊天模板。若做长度归一化，目标会发生变化，应说明是变体。实现使用 logsigmoid 以保证数值稳定。
