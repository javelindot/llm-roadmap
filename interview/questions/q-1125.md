# k个有序链表合并，时间复杂度

## 答案

**用最小堆维护每条非空链表的当前节点，每次取最小者并推进该链表。** 假设输入链表有序、无环且不共享节点。
```python
import heapq
from itertools import count

def merge_k_lists(lists):
    """复用原节点合并有序链表，序号避免同值节点直接比较。"""
    heap = []
    serial = count()
    for node in lists:
        if node is not None:
            heapq.heappush(heap, (node.val, next(serial), node))
    head = tail = None
    while heap:
        _, _, node = heapq.heappop(heap)
        nxt = node.next
        if nxt is not None:
            heapq.heappush(heap, (nxt.val, next(serial), nxt))
        if tail is None:
            head = node
        else:
            tail.next = node
        tail = node
    if tail is not None:
        tail.next = None
    return head
```
总节点数 N、链表数 k，时间 O(N log k)（k=1 时 O(N)），堆空间 O(k)。分治两两合并也有相同量级；顺序反复并入一条大链表最坏可到 O(Nk)。
