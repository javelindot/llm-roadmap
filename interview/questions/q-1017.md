# PPO/GRPO 微调后，如何防止模型在分布外(OOD)问题上性能崩塌？

## 答案

防止 PPO/GRPO 的 OOD 退化，需要**约束更新、保持数据覆盖并独立验证通用能力**。可采用参考模型 KL、较小更新步数/学习率、混合领域与通用任务，以及按需加入 SFT 辅助损失。
奖励只覆盖训练域时，策略可能学到捷径；建立 OOD、困难、不同语言和安全回归集，监控质量、回答长度、拒答率、熵与奖励分项。
按固定训练 token 或预算保存 checkpoint，在验证集选择并可回滚。KL 小不能单独证明能力没退化，训练奖励升高也不能替代 OOD 测试。
