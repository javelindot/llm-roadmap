# SFT 的 loss 如何只计算回答部分？(如何 ignore padding token?)

## 答案

**给提示词、特殊不计分位置和 padding 的 labels 设置 -100，仅回答 token 保留真实 token id。** Hugging Face 常用的交叉熵会忽略 -100。
```python
def make_labels(input_ids, answer_mask, attention_mask):
    """只监督回答区域；真实 EOS 可保留，padding 始终忽略。"""
    if not (len(input_ids) == len(answer_mask) == len(attention_mask)):
        raise ValueError("length mismatch")
    return [token if answer and visible else -100
            for token, answer, visible
            in zip(input_ids, answer_mask, attention_mask)]
```
answer_mask 应依据实际 chat template 和角色边界生成，不能只靠某个字符串的字符长度。decoder-only 模型通常内部移位 logits/labels，不要再手动移位一遍。pad 与 EOS 共用 id 时用 attention_mask 区分，不能按 token id 把真实 EOS 一并屏蔽。
