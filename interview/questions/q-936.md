# 2．讲一下大模型训练和推理的流程， SFT 和 RLHF 的作用分别是什么

## 答案

训练通常包含**数据整理与分词 → 预训练 → SFT → 按需偏好对齐 → 评测与发布**。预训练通过大量文本的下一个 token 预测学习通用表示和知识；SFT 用指令数据学习任务格式与指令遵循；RLHF 等方法进一步优化偏好、安全或可验证任务奖励。
推理则是加载参数、分词和模板化输入、prefill 计算上下文并建立 KV Cache，再逐 token decode，最后停止与后处理。KV Cache、batch 调度、采样和量化决定部分延迟及吞吐。
SFT 与 RLHF 都不能保证事实正确；上线仍需任务评测、权限控制、知识检索和监控。并非每个模型都必须经过全部阶段。
