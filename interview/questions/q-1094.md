# 大模型的训练的完整流程是什么样子的？为什么要先经过SFT微调，在RL？

## 答案

完整流程可概括为**数据治理 → 预训练/继续预训练 → SFT → 可选偏好/RL → 评测 → 推理优化与发布**。各阶段保存数据与配置版本，保留独立能力、安全和业务测试集。
先做 SFT 可让策略具备基本指令遵循和合理输出，使 RL 的探索与奖励更有效；RL 再优化难以由 token 似然充分表达的最终结果。
但 SFT 后 RL 不是必经路线，一些推理工作探索基础模型直接 RL。选阶段要依据任务、反馈、预算与实测收益，不能把流程当成所有模型统一配方。
