# 反问：会做生成式推荐吗

## 答案

如被问“会做生成式推荐吗”，先明确实际经验，再说明可实施方案：**用户历史编码 → 物品语义 ID/离散 token → 自回归生成候选 → 约束与重排**。
物品 ID 可由内容/协同表示量化构建，训练用真实交互序列，推理要映射有效物品并处理库存、权限、去重和多样性。
主要难点是 ID 质量、无效生成、候选覆盖、冷启动、曝光偏差与延迟。先与双塔召回+精排基线比较同预算的 Recall/NDCG 和线上指标；通用 LLM 直接输出商品名字通常不足以成为可靠推荐服务。
