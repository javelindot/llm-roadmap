# 二面继续开挖项目，这次问的问题围绕深度学习相关的问的，主要围着项目问，问了训练中的具体调试问题

## 答案

训练调试按**数据 → 前向/loss → 反向 → 优化 → 验证**逐层排查。先在极小数据上尝试过拟合，核对标签、模板、mask、padding 与样本顺序。
loss 不降检查学习率、参数是否可训练、梯度是否传播；NaN 检查数值精度、溢出和异常数据；OOM 区分参数、激活、长序列和内存泄漏；验证差则查泄漏、分布与过拟合。
记录模型/数据/环境版本，每次只验证一个假设，用日志与消融支持结论。面试应举实际问题、定位证据和结果，不编造调试经验。
