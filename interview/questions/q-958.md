# 🔥 代码题：lc129 求根节点到叶节点数字之和

## 答案

**深度优先遍历时累积路径数字，到叶节点再计入结果。** 假设节点值是 0-9，路径 `1 -> 2 -> 3` 对应 123。

```python
def sum_numbers(root):
    """汇总所有根到叶路径组成的数字，空树返回零。"""
    def dfs(node, prefix):
        """将当前节点追加到路径数字，只有叶节点贡献最终结果。"""
        if node is None:
            return 0
        value = prefix * 10 + node.val
        if node.left is None and node.right is None:
            return value
        return dfs(node.left, value) + dfs(node.right, value)

    return dfs(root, 0)
```

每个节点访问一次，时间复杂度 O(n)，辅助空间 O(h)，h 为树高。极端退化树可能超过 Python 递归深度，可改用栈保存 `(node, prefix)`。

边界测试包括空树、单节点、只有一侧子树以及路径中含 0。不要把所有节点的值相加，也不要在非叶节点就提前累计结果。
