# 你做的 Agent 使用了多少个外部工具，在调用链条上如何保障故障容错和超时机制？

## 答案

工具数量应按实际项目回答，并列出读取、计算和写入工具。可靠性主要取决于工具契约与失败处理，不能用工具多证明系统成熟。

给每个工具定义 Schema、权限、超时、可重试性和结构化错误；整条任务另设总截止时间与预算，子调用不能无限叠加各自超时。

读请求的临时故障可有限退避重试；限流遵守服务端提示；业务拒绝不重试。写请求采用幂等键，网络超时后先查真实状态，因为超时不代表操作没有执行。

独立只读工具可并行，有依赖或写入关系的动作按顺序执行。用熔断、替代数据源和人工升级兜底，并在 trace 中记录工具名、参数摘要、重试次数与回执。
