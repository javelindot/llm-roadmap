# Qwen3的技术原理

## 答案

**Qwen3 的技术要按具体型号区分。** 家族包含 Dense 和 MoE 模型，后训练强调推理与非推理模式、推理能力迁移以及综合能力/偏好优化；公开报告还描述了更广的多语言预训练数据与分阶段训练。
使用端要遵循模型对应的 chat template 和 thinking 控制方式，避免把“关闭思考”只写成普通自然语言约束。长上下文、工具能力和支持精度也以具体模型卡为准。
工程评价同时看最终正确率、思考 token 预算、延迟和成本。不要把某个型号的总参数、激活参数或上下文长度推广为整个系列的统一规格。
