# vLLM框架是怎么做推理加速的？

## 答案

vLLM 的代表性能力是 PagedAttention 和 continuous batching。前者将 KV Cache 分块管理，减少按最大长度预留造成的碎片；后者在生成迭代间动态接纳和移除请求，提高 GPU 利用率。

具体版本还可能支持 prefix caching、优化注意力算子、量化、张量并行、推测解码等，效果取决于模型、硬件和配置，不能把所有功能视为默认同时开启。

PagedAttention 主要改善缓存管理与并发可容纳量，并不减少模型本身的参数。推测解码的收益则依赖草稿模型成本与接受率；长输入任务还需要分析 prefill 调度。

测性能时固定输入输出长度分布、采样参数和硬件，比较 TTFT、尾延迟、输出吞吐、成功请求数及显存。更大的 batch 可能提升吞吐但恶化单请求延迟。
