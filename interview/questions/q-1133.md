# adagrad没答上来，只让我回答了adam怎么计算的

## 答案

Adam 的计算分为**矩估计、偏差校正和参数更新**：
```text
m_t = β1*m_(t-1) + (1-β1)*g_t
v_t = β2*v_(t-1) + (1-β2)*g_t²
m_hat = m_t / (1-β1^t)
v_hat = v_t / (1-β2^t)
θ_t = θ_(t-1) - η*m_hat/(sqrt(v_hat)+ε)
```
零初始化导致早期矩偏小，偏差校正补偿这一点。ε 防止除零/改善数值稳定。AdamW 将权重衰减单独作用于参数；它与将 L2 直接加到 Adam 梯度中不等价。
说明各项都是逐参数运算，并补充学习率调度、梯度裁剪和混合精度的实际配置。
