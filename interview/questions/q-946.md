# LGB只用了统计特征吗，已有embedding，为什么不用深度模型呢

## 答案

有 embedding 不等于一定要用深度模型。LightGBM 可处理统计特征、类别编码及 embedding 派生特征，在标签不多、特征工程成熟、迭代和部署成本受限时很有竞争力。

可以将 embedding 维度、降维结果、聚类 ID 或相似度作为特征，但要检查高维输入带来的训练成本。深度模型更擅长端到端表示学习和复杂交互，前提是有足够有效数据、训练资源及稳定线上链路。

选择应来自公平实验：相同数据和时间划分，对比统计特征 LGB、加入 embedding 的 LGB，以及使用 embedding 的 DNN，观察 AUC、校准、业务收益、延迟和成本。

防止把未来信息、点击后的行为或用测试标签训练的 embedding 注入特征。项目面试应展示真实对比，不用「树模型更可解释」代替效果证据。
