# vLLM 中使用的技术是否熟悉（如 Paged Attention 、 KV Cache )?

## 答案

**vLLM 的 PagedAttention 通过分块管理 KV Cache，减少连续内存分配造成的浪费。** 序列的逻辑块映射到物理块，支持动态扩展及部分共享；连续批处理则在迭代级别接纳新请求和移除完成请求。
KV Cache 存历史 token 的 K/V，decode 时避免重算此前 token 的投影，但仍需对历史缓存做注意力。标准注意力缓存量约为 2×层数×token数×KV头数×头维度×元素字节数；GQA/MQA 可减少 KV 头数。
PagedAttention 不消除 KV 数据本身，也不是 FlashAttention 的同义词。性能还取决于 prefill/decode 调度、长度分布、显存、并行策略与所用版本。
