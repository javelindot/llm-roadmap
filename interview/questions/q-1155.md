# 开放场景:如果你有一个待优化的模型和一堆query,你怎么利用PPO来优化模型?

## 答案

**一堆 query 不足以直接做 PPO，还需要可靠奖励和评测。** 先建立模型基线与独立 query 测试集，再根据任务定义答案校验、代码测试、人工偏好或奖励模型。
由当前策略为训练 query 采样回答，保存 old logprob，计算奖励与参考 KL、价值/GAE，再用 PPO 裁剪更新 actor 和 critic。限制学习率、更新轮数和采样预算，监控 KL、裁剪比例、奖励与任务质量。
如果只有偏好对可先考虑 DPO；没有可信反馈则先做数据/评测。最终用独立质量、安全和 OOD 集选择 checkpoint，防止奖励上涨但业务能力下降。
