# 讲解DeepSeek R1的训练流程和基本原理。

## 答案

**R1 的推理增强主要来自后训练中的强化学习与高质量数据迭代。** R1-Zero 展示了从基础模型直接 RL 的路径；正式 R1 加入冷启动 SFT，以改善可读性等问题。
论文描述的主要流程为：冷启动推理数据 SFT → 面向推理的 RL → 拒绝采样构造推理与通用数据，再次 SFT → 进一步 RL 以兼顾能力与偏好。GRPO 用每提示多样本奖励的相对差异构造优势，无单独 critic。
蒸馏版则在教师生成的数据上训练更小模型。MLA 和 MoE 是基础模型架构，GRPO 是训练算法；最终性能还需用独立可验证任务及 OOD 集评估。
