# 力扣74题：搜索二维矩阵

## 答案

LC74 假设**每行升序，且下一行首元素大于上一行末元素**，可把矩阵视为长度 m×n 的有序数组进行二分。
```python
def search_matrix(matrix, target):
    """利用全局行序性质进行二分，空矩阵返回假。"""
    if not matrix or not matrix[0]:
        return False
    rows, cols = len(matrix), len(matrix[0])
    lo, hi = 0, rows * cols
    while lo < hi:
        mid = (lo + hi) // 2
        value = matrix[mid // cols][mid % cols]
        if value < target:
            lo = mid + 1
        else:
            hi = mid
    return lo < rows * cols and matrix[lo // cols][lo % cols] == target
```
时间 O(log(mn))，空间 O(1)。矩阵需矩形且满足该全局有序条件；若只有行列各自有序，属于 LC240，应采用其他搜索方式。
