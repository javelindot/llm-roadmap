# Transformer模型中计算量(FLOPs)的分析

## 答案

按乘加计2次 FLOP，设序列长度 n、隐层 d、FFN 宽度4d，**标准 Transformer 层的前向近似为 24nd²+4n²d**。
Q/K/V 与输出投影约8nd²；两层 FFN 约16nd²；QK^T 和注意力乘 V 约4n²d。还未计 softmax、归一化、激活与词表输出，门控 FFN 的常数也不同。
Dense 模型训练常用粗估 C≈6ND（N 参数量、D 训练 token 数），但长上下文注意力、重计算和 MoE 会改变估算。decode 由于 KV Cache 和内存读写也不能只用该 FLOP 公式预测延迟。
