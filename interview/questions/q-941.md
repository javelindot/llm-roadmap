# 3.介绍MoE （混合专家）架构核心优势。

## 答案

**混合专家架构用稀疏激活提高参数容量与计算成本之间的效率。** 每个 MoE 层有多个专家 FFN，router 为 token 选择部分专家，例如 top-2，然后按路由权重合并输出。
它的核心收益是总容量可以大于单次前向实际激活的容量，有利于扩大模型而不按同样比例增加每 token 计算。但性能仍受路由器、共享层和专家间 all-to-all 通信影响。
工程上需控制专家负载、路由抖动、容量溢出和设备分布。对比 Dense 应统一训练数据与计算预算；不能仅看总参数、或认为专家一定对应人类定义的知识领域。
