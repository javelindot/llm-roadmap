# 是否有过AI训练和推理框架的开发经验

## 答案

这类问题要明确个人贡献属于使用、集成、调优还是底层开发。调用训练框架或搭建推理 API 不等于实现过分布式通信、调度器或算子。

训练侧可介绍真实的数据管道、精度与 loss mask、checkpoint、并行、OOM 排查和吞吐优化；推理侧可介绍模型适配、动态批处理、缓存、流式协议、取消、压测和质量回归。

若做过框架开发，给出具体模块、改动原理、兼容性、单元与端到端验证，以及改动前后的结果。区分自己实现的部分和已有框架提供的能力。

没有底层经验时如实说明，仍可通过 profiler 分析、代码阅读和最小实验展示理解。不要把未测量的优化收益或团队整体工作写成个人成果。
