# 代码题:lc141 环形链表

## 答案

**快慢指针判断环：慢指针走1步，快指针走2步，相遇则有环。**
```python
def has_cycle(head):
    """判断链表是否有环，空链表或正常终点返回假。"""
    slow = fast = head
    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```
有环时二者在环上的相对速度为1，最终相遇；无环时快指针先到 None。时间 O(n)，额外空间 O(1)。比较节点身份，不比较节点值；测试单节点自环、重复值无环、长前缀带环。
