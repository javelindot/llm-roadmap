# 然后聊了半小时onerec，重点在多模态tokenizer和语义id

## 答案

讨论 OneRec 等生成式推荐时，核心是**将物品表示为可生成的离散标识序列，而非只对固定候选逐个打分**。应以面试指定的论文版本解释，避免混用不同系统。
多模态内容编码器可融合标题、图像/视频等表示，再通过量化等方法构建 semantic ID；推荐模型根据用户历史生成 ID/token，映射回真实物品。
需要解决 ID 碰撞、冷启动、内容更新、无效/失效物品、约束解码和延迟。离线看 Recall/NDCG 与 ID 覆盖，线上看满意度与收益；内容语义邻近不一定等于协同推荐相关。
