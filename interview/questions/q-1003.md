# 代码题:lc143 重排链表

## 答案

**先找中点，再反转后半链表，最后交替合并。** 重排只修改 next 指针，不改变节点值。
```python
def reorder_list(head):
    """将链表原地重排为首尾交替顺序。"""
    if head is None or head.next is None:
        return
    slow = fast = head
    while fast.next and fast.next.next:
        slow, fast = slow.next, fast.next.next
    second, slow.next = slow.next, None
    prev = None
    # 反转后半段，并与前半段断开，避免合并时产生环。
    while second:
        nxt = second.next
        second.next, prev, second = prev, second, nxt
    first, second = head, prev
    while second:
        a, b = first.next, second.next
        first.next, second.next = second, a
        first, second = a, b
```
时间 O(n)，额外空间 O(1)。测试空链表、1/2 个节点以及奇数/偶数长度；不能忘记在中点断链。
