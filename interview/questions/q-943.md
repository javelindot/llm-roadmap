# 5. 对比 LORA 微调 Qwen 模型两种微调方式的性能表现。

## 答案

题目没有说明“两种方式”是哪两种，应先确认是**LoRA 与全量微调**，还是 LoRA 与 QLoRA，或不同目标层/秩。
LoRA 冻结基础权重，只训练低秩适配器，梯度和优化器状态较少；全量微调表达自由度更大，成本也更高。QLoRA 进一步量化基础权重，再以较高精度计算并训练适配器，显存更低但增加量化处理。
实验统一 Qwen 版本、模板、数据切分与训练 token 预算，比较任务质量、通用能力、峰值显存、tokens/s 和部署方式。没有实测时只能说明预期权衡，不能给出固定性能差值。
