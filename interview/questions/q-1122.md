# 如何将字符串xxxxyy转换为4x2y的格式并使用哈希表实现？

## 答案

先确认要求是**相邻游程压缩**还是**全局字符计数**；对 xxxxyy 两者都得到4x2y，但对 xyx 分别得到1x1y1x或2x1y。
若题目明确要求哈希计数，可使用保持首次出现顺序的字典：
```python
def encode_counts(text):
    """按字符首次出现顺序输出总频次，不保留原始游程位置。"""
    counts = {}
    for char in text:
        counts[char] = counts.get(char, 0) + 1
    return "".join(f"{count}{char}" for char, count in counts.items())
```
时间 O(n)，哈希空间 O(k)，k 为不同字符数。若要求游程压缩，应线性扫描并在字符切换时输出计数，不能合并不相邻字符。字符串含数字时，压缩格式还需转义或分隔才能无歧义恢复。
