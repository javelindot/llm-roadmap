# PPO的原理？从维护的四个model讲，再详细讲一下训练流程和损失函数各个参数含义？

## 答案

经典 LLM PPO 涉及**策略 actor、旧策略快照、参考模型、奖励模型和价值 critic**；“四个模型”常指 actor/ref/reward/critic，旧策略是采样时的 actor 快照，不一定额外常驻一套模型。
流程是 actor 采样 → reward 评分并加入 KL 成本 → critic 估值 → 计算回报/GAE → 在固定 rollout 上进行若干 minibatch 更新。PPO 最大化 E[min(ρA,clip(ρ,1-ε,1+ε)A)]，ρ=πθ/πold。
价值损失可写为 E[(Vθ-R)^2]，总最小化损失为 -Jpolicy+c_v Lvalue-c_e H，加上所选 KL 项。ε 限制更新幅度，γ 是折扣，λ 是 GAE 权衡参数。参考模型一般固定，旧策略随下一轮采样刷新。
