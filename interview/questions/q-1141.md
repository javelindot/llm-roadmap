# 三面:LLM 与推荐结合的可落地方案，小红书场景下的设计

## 答案

LLM 与内容推荐可从**离线内容理解、用户兴趣表示和受控生成召回**落地。小红书类场景可用多模态模型提取笔记主题、实体、风格、质量和商业属性，增强新内容召回；用户历史可形成时间敏感兴趣表示。
在线使用双塔/序列模型召回及多任务精排，LLM 可离线生成语义 ID 或辅助候选解释，避免每个请求都做昂贵全量推理。
考虑隐私、内容审核、冷启动、曝光偏差与作者公平。以固定基线比较新内容覆盖、满意度、负反馈、延迟和成本；具体平台内部实现应明确未知。
