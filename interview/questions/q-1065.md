# 有三个工人(x y z)和需要完成的任务数(n), Xy z表示,每个工人可以完成的最大任务数目. 问一共有多少种分配方式,工人可以完成零个任务

## 答案

求非负整数解 a+b+c=n，且 a≤x、b≤y、c≤z。**用隔板法求无限制解，再用容斥排除超上限情况。**
```python
def count_assignments(n, x, y, z):
    """计算三个有上限工人的任务分配数，任务按数量分配。"""
    if any(type(v) is not int or v < 0 for v in (n, x, y, z)):
        raise ValueError("nonnegative integers required")
    caps = (x, y, z)
    total = 0
    # 选中的工人视为超限，变量平移后用隔板法计数。
    for mask in range(8):
        rest = n - sum(caps[i] + 1 for i in range(3) if mask & (1 << i))
        ways = (rest + 2) * (rest + 1) // 2 if rest >= 0 else 0
        total += (-1 if mask.bit_count() % 2 else 1) * ways
    return total
```
时间和空间 O(1)。n=0 返回1；n>x+y+z 返回0。这里任务按数量不可区分，若每个任务有独立身份，计数公式不同。
