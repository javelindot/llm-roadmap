# rollout数量 batchsize数量和计算资源(卡的数量)有什么关系？线性？非线性？

## 答案

设每轮有 B 个提示、每提示采样 G 个回答，则 **rollout 数为 B×G**；总 token 量还取决于提示和输出长度。优化用的 minibatch、梯度累积和 rollout batch 是不同概念。
数据并行有效 batch 通常为 每卡 microbatch×累积步数×数据并行度；张量并行、流水线并行占用的卡不能直接计入该倍数。
增加卡数可能提升采样吞吐，但受 KV Cache、序列长度、调度、通信和 reward 服务瓶颈影响，关系通常不是严格线性的。先测采样、奖励和训练各阶段 tokens/s，再确定并行拓扑与显存余量。
