# 讲一下你对 agent 和 Workflow 的理解

## 答案

**Workflow 用预先定义的流程组织执行，Agent 让模型在边界内选择下一步动作。** 两者可以组合：工作流负责可靠性，Agent 处理难以穷举的判断。

例如退款流程中的订单查询、权限检查、审批和账务写入适合确定性工作流；分析投诉原因、选择检索策略适合 Agent。Agent 自主程度更高，但也增加延迟、成本和错误路径。

工程上用状态图定义输入输出、工具白名单、超时、checkpoint 和终止条件。任务简单、路径稳定时优先工作流；输入变化大且动作选择难以写成规则时，在局部引入 Agent。

验收应比较任务成功率、恢复能力、平均工具次数和单任务成本。模型动态选工具不等于整个系统都需要交给模型自由规划。
