# Reward Model的本质是学习同一状态下的不同动作的偏好

## 答案

这句话需要限定：**成对奖励模型学习同一提示下回答的相对偏好，RL 价值函数则估计当前策略的未来回报。**
典型损失为 -log σ(r(x,y+)-r(x,y-))，模型通常给完整回答一个标量。只用成对偏好时，分数加同一提示相关常数并不改变偏好，因此绝对分数不天然可跨提示比较。
在 LLM token MDP 中，动作通常是一个 token，完整回答是轨迹；不能未经说明把完整回答评分等同于每一步动作的真实奖励。需要校准、检查偏差和奖励投机。
