# 如果子agent回复不对怎么办？反思？跳不出去怎么办？限制次数？

## 答案

主 Agent 应按预先定义的验收规则检查子 Agent 的输出，例如 Schema、证据引用、工具回执和业务约束。仅让另一个模型说「对不对」不足以保证正确。

首次失败返回具体反馈，让子 Agent 在限定范围内修正；再次失败可以缩小任务、换工具或转人工。反思需要新证据或可执行改进，反复输出相同思考没有价值。

为每个任务设置最大尝试次数、总时间、token、金额和工具调用预算，并检测重复状态或重复动作。达到上限后保存状态，明确返回失败或需要人工处理。

写操作失败或结果未知时必须先核验外部回执，重规划不能重复执行已有动作。评价恢复策略应统计实际任务成功率、重复副作用及额外成本。
