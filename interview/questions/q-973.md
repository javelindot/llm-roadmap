# 讲一下什么场景下用SFT，什么场景下用RL

## 答案

**SFT 适合有高质量示范、需要学习格式和任务行为的场景；RL 适合最终结果可评分、需要探索不同策略的场景。**
例如稳定 JSON 输出、领域问答风格和工具格式可先 SFT；数学正确性、代码测试通过和多步工具任务成功率可进一步优化可验证奖励。只有离线偏好对时可考虑 DPO。
实践通常先建立 SFT 基线，再判断奖励是否与真实目标一致、探索是否有收益、训练预算是否足够。RL 也会放大奖励漏洞和分布偏差。知识更新、权限和精确计算分别通过检索、服务端授权和工具处理，不能统一归结为训练。
