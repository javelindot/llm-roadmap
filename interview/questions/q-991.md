# 给你一个场景，假设让你用 bert 或者 transformer 做一个文本分类，你能很快搭建吗

## 答案

**可以用预训练 BERT 加分类头快速建立文本分类基线。** 准备文本/标签，按用户或时间划分训练与验证，使用匹配 tokenizer，设置截断和动态 padding，再用 AutoModelForSequenceClassification 与 Trainer 或 PyTorch 训练。
单标签多分类使用交叉熵，二分类也可用两类交叉熵；多标签则通常用每类 sigmoid+BCEWithLogitsLoss。注意 BERT 的 attention_mask 屏蔽 padding，与 loss 标签类型匹配。
评测看 macro-F1、混淆矩阵及类别召回，处理不均衡和长文本；推理复用 tokenizer、label mapping 并设置 eval/no_grad。先跑少量数据检查 loss 能下降，再扩大训练。
